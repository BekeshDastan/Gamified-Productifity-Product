# ASCEND · Level Up Your Life

Веб-приложение для личной дисциплины: задачи, цели, календарь, привычки и
объяснимый игровой прогресс. Интерфейс на русском. Данные закрыты по умолчанию.
Пропуски не отнимают заработанные уровни.

Проект находится в разработке. Источник требований и последовательности работы:
[техническое задание](docs/ASCEND_TECHNICAL_SPEC.md). Отметка в плане означает
проверенную реализацию, а не только наличие макета. Текущий статус и результаты
проверок: [журнал разработки](docs/progress.md).

## Принципы

Бизнес-правила выполняются в Go API; Next.js отвечает за представление.
Планирование, отчёты и подсказки используют формулы и правила. Продукт не
обращается к нейросетям и не требует AI-ключей. Подробнее:
[ADR-001](docs/adr/001-deterministic-modular-monolith.md).

Разработка идёт небольшими проверяемыми коммитами по C001–C200. Основной продукт
должен работать без подключения внешних провайдеров. Инструкции запуска
добавляются вместе с соответствующими работающими компонентами.

## Быстрый запуск

Нужны Node.js 22.22.0, npm 10.9.4, Go с поддержкой автоматической загрузки
toolchain (используется 1.26.9) и запущенный Docker Desktop / Docker Engine.

В PowerShell из корня проекта:

```powershell
npm ci
Copy-Item .env.example .env
node -e "const fs=require('node:fs');const crypto=require('node:crypto');const p='.env';let s=fs.readFileSync(p,'utf8');if(/^AUTH_SIGNING_KEY=\r?$/m.test(s)){s=s.replace(/^AUTH_SIGNING_KEY=\r?$/m,'AUTH_SIGNING_KEY='+crypto.randomBytes(32).toString('base64'));fs.writeFileSync(p,s);}"
npm run dev
```

При существующем `.env` не перезаписывайте его. Команда запускает базу, API,
worker и web. Сайт: <http://localhost:3000>. API: <http://127.0.0.1:8080>.
Вход, регистрация и восстановление доступны через интерфейс и API с Origin/CSRF.
Неизвестные пути возвращают 404. Ключ AUTH_SIGNING_KEY не публикуйте и сохраняйте
между перезапусками; его смена инвалидирует access и pre-auth cookie.
Для завершения всех входов также требуется отзыв серверных сессий.
Проверки сервера: `/health/live` и `/health/ready` (503 при недоступной БД).
Ctrl+C останавливает процессы приложения; база остаётся в Docker с сохранёнными
данными. Остановить базу: `docker compose stop`.

| Команда npm                | Эквивалент make         | Действие                                        |
| -------------------------- | ----------------------- | ----------------------------------------------- |
| `npm run dev`              | `make dev`              | Локальное окружение                             |
| `npm run lint`             | `make lint`             | Политика файлов, формат, ESLint, TypeScript, Go |
| `npm test`                 | `make test`             | Tooling, component и Go unit tests              |
| `npm run check-changed`    | `make check-changed`    | Lint + unit + PostgreSQL + build + UI/auth E2E  |
| `npm run build`            | `make build`            | Production web и два Go-бинарника               |
| `npm run migrate`          | `make migrate`          | Forward-миграции goose к явному DATABASE_URL    |
| `npm run seed`             | `make seed`             | Пока явный отказ; каталог ещё не создан         |
| `npm run test:integration` | `make test-integration` | Реальные PostgreSQL и локальная почта           |
| `npm run test:e2e`         | `make test-e2e`         | Playwright Chromium: темы, меню, a11y, ошибки   |
| `npm run test:auth-e2e`    | —                       | Реальные Go API, PostgreSQL, SMTP и Chromium    |

Windows не требует установки make: команды npm используют тот же обработчик.
Неподключённые наборы завершаются с ошибкой и пояснением; фиктивных зелёных тестов
нет. `make backup`, `make restore-verify`, `make seed-demo` также пока отказывают
в выполнении. Production web после build: `npm run start --workspace @ascend/web`.

Настройки и версии: [dependencies](docs/dependencies.md).
Браузерный набор: сначала `npx playwright install chromium` из `apps/web`,
затем `npm run build:web` и `npm run test:e2e` из корня. Он сам запускает
production web на 127.0.0.1:3100 и останавливает его после тестов.
`check-changed` включает сборку web и E2E; перед ним остановите dev, чтобы
два процесса не меняли один `.next` одновременно.
Локальная БД и сохранность данных: [runbook](docs/runbook.md).

## Текущая готовность

Реализованы C001–C160 (20 из 25 функциональных этапов): серверная платформа, лендинг, адаптивная оболочка,
доступные компоненты, авторизация, профиль, настройки, онбординг, задачи, цели, календарь, планирование, привычки, прогрессия, персонаж, достижения, магазин наград, боссы, концентрация, дневник с ритуалами и живой Dashboard.
`/app` показывает реальные задачи, план, сроки, события и быстрые отметки привычек.
Работают вход, регистрация, email verification, восстановление пароля и управление
устройствами и смена пароля с проверкой текущего. В аккаунте сохраняются имя,
ник, аватар, IANA timezone, формат дат/времени, рабочие интервалы и дни отдыха,
направления/теги с архивом, приватность, тема, движение и предпочтения интерфейса.
После регистрации короткое знакомство помогает сразу создать настоящую задачу на сегодня.
Его можно пропустить; завершение сохраняется в аккаунте. Подробная настройка необязательна,
её можно продолжить на другом устройстве и открыть повторно.
Стартовый черновик задачи из подробной настройки однократно переносится при открытии раздела задач.
Черновик цели однократно переносится в раздел целей. Идею привычки можно открыть в форме,
выбрать норму и расписание и однократно создать привычку с явным подтверждением.
Ежедневные действия вынесены в начало навигации, игровые разделы раскрываются отдельно.
Кнопка добавления работает на компьютере и телефоне; каталог настроек доступен в `/app/settings`.
Отдельный [UX-аудит и отчёт о редизайне](docs/UX_REDESIGN.md) описывает изменения,
сохранённые возможности и фактические проверки.
В `/app/quests` работают создание и редактирование, фильтры и сохранённые
представления, список и Kanban, переходы статусов с причинами, история,
обязательные подзадачи и блокирующие связи, шаблоны, пакетные действия до
50 задач, архив и восстановление. Два редактора получают предупреждение
о конфликте версии. Плановая дата хранится отдельно от дедлайна с часовым поясом.
Вложения приватны: MIME/размер/квоты проверяются сервером, скачивание возможно
после проверки сканером. Локальный антивирус пока не настроен, поэтому новые
файлы остаются на проверке; подключение описано в runbook. XP выдаётся
централизованно по проверенным правилам и истории наград. Связь и фильтрация задач по целям работают.
В `/app/goals` доступны цели по этапам, обязательным листьям задач и числовому
журналу. Есть шесть редактируемых шаблонов с предпросмотром дат и подтверждением,
пауза, явное подтверждение достижения, завершение без достижения, пересмотр и архив.
Прежние критерии и планы сохраняются в истории; исправление источника ниже
подтверждённого порога открывает цель снова. Просроченная дата не завершает цель.
Язык интерфейса — русский; язык дат — ru/en. Социальная публикация не подключена,
профили закрыты. Звук, игровой режим и порядок виджетов сохраняются как предпочтения
для будущих разделов. В `/app/habits` работают три типа отметок, недельные/месячные нормы,
честные серии, паузы, будущие версии норм, архив и журнал исправлений.
Ресурсы и лицензии: [каталог](docs/assets.md).

## Лицензия

[MIT](LICENSE). Сторонние ресурсы и их лицензии учитываются отдельно.

В /app/calendar доступны день/неделя/месяц/год/список, события без времени,
временные блоки и несколько блоков на задачу, переносы и изменение длительности
мышью или формой. Повторяемые задачи имеют отдельные экземпляры, отмену,
изменение будущей части и конца серии. История плана и дедлайны показаны отдельно.
FullCalendar Standard не требует Premium-ключа; все данные принадлежат аккаунту.

Опыт и награды доступны в `/app/progress`: уровень, баланс, rolling-квоты и история с источниками. Исправления сохраняют исходную версию правил и суммы.

Персонаж и навыки: `/app/character`; 30 проверяемых достижений: `/app/achievements`. 20 оригинальных MIT SVG, бесплатный полный образ, сохраняемая экипировка, титулы и рекорды с источниками. Разделы фокуса/сезонов/совместных испытаний пока не выдают достижения без подтверждённых данных.

В `/app/rewards` доступны личные награды с подтверждением цены, атомарные покупки,
возврат до получения и косметика. Бесплатные подарки за три цели и три привычки
выдают один сохранённый результат; веса открыты, дубли исключаются до полного набора.
В `/app/bosses` HP следует прогрессу существующей цели. Победа требует подтверждения
критерия, не создаёт второй XP; исправления источника обновляют HP и право на титул.
Главный босс выбирается на месяц с историей смен.

В `/app/focus` работают свободный таймер, Pomodoro и пяти­минутный старт из задачи.
Сессия восстанавливается между вкладками и устройствами по серверным отметкам.
Паузы и перерывы исключаются; после 4 часов работы или 8 часов от старта нужен итог.
Подтверждение не закрывает задачу и не добавляет XP. Фактическое время выбирается
из подтверждённых сессий либо задаётся вручную вместо их суммы; история сохраняется.

В `/app/journal` доступны частные записи с безопасным Markdown, датами, тегами и целями.
Черновики живут только в текущей вкладке и очищаются при выходе или смене аккаунта.
Утренний ритуал подтверждает один план дня, вечерний разбор показывает реальные
итоги и допускает пустое настроение/энергию. Личные чек-листы редактируются
с сохранением прежних снимков. Weekly Reset сначала показывает исходные даты,
затем атомарно применяет выбранные переносы, архив и планы следующей недели;
повтор не создаёт вторых задач или планов.

## Личные уведомления

`/app/notifications` хранит историю, прочтение и напоминания. Настройки каналов,
тихих часов, часового пояса и частоты доступны в `/app/settings/notifications`.
Email и push по умолчанию выключены; письмо требует подтверждённой почты,
push — отдельного согласия браузера и включения типов. Перенос напоминания
сохраняет дедлайн задачи. Принятие SMTP/push сервисом отличается от
неизвестного исхода и не доказывает получение человеком.

Настройка VAPID, отзыв устройств и ограничения проверки реальных провайдеров:
[инструкция эксплуатации](docs/runbook.md#уведомления-c153c160).
