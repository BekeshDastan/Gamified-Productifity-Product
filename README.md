# ASCEND · Level Up Your Life

Веб-приложение для личной дисциплины: задачи, цели, календарь, привычки и
объяснимый игровой прогресс. Интерфейс на русском. Данные закрыты по умолчанию.
Пропуски не отнимают заработанные уровни.

Проект находится в разработке. Источник требований и последовательности работы:
[техническое задание](docs/ASCEND_TECHNICAL_SPEC.md). Отметка в плане означает
проверенную реализацию, а не только наличие макета. Текущий статус и результаты
проверок: [журнал разработки](docs/progress.md).

## Структура

| Путь                | Назначение                                                      |
| ------------------- | --------------------------------------------------------------- |
| `apps/web`          | Next.js App Router, TypeScript, интерфейс                       |
| `services/api`      | Go API, worker, доменные правила, SQL и тесты                   |

| `.github/workflows` | Проверки сборки и качества                                      |

## Принципы

Бизнес-правила выполняются в Go API; Next.js отвечает за представление.
Планирование, отчёты и подсказки используют формулы и правила. Продукт не
обращается к нейросетям и не требует AI-ключей. Подробнее:
[ADR-001](docs/adr/001-deterministic-modular-monolith.md).

Разработка идёт небольшими проверяемыми коммитами по C001–C200. Основной продукт
должен работать без подключения внешних провайдеров. Инструкции запуска
добавляются вместе с соответствующими работающими компонентами.

## Быстрый запуск

Нужны Node.js 22.22.0, npm 10.9.4, Go с поддержкой автоматической загрузки
toolchain (используется 1.26.9) и запущенный Docker Desktop / Docker Engine.

В PowerShell из корня проекта:

```powershell
npm ci
Copy-Item .env.example .env
node -e "const fs=require('node:fs');const crypto=require('node:crypto');const p='.env';let s=fs.readFileSync(p,'utf8');if(/^AUTH_SIGNING_KEY=\r?$/m.test(s)){s=s.replace(/^AUTH_SIGNING_KEY=\r?$/m,'AUTH_SIGNING_KEY='+crypto.randomBytes(32).toString('base64'));fs.writeFileSync(p,s);}"
npm run dev
```

При существующем `.env` не перезаписывайте его. Команда запускает базу, API,
worker и web. Сайт: <http://localhost:3000>. API: <http://127.0.0.1:8080>.
Вход, регистрация и восстановление доступны через интерфейс и API с Origin/CSRF.
Неизвестные пути возвращают 404. Ключ AUTH_SIGNING_KEY не публикуйте и сохраняйте
между перезапусками; его смена инвалидирует access и pre-auth cookie.
Для завершения всех входов также требуется отзыв серверных сессий.
Проверки сервера: `/health/live` и `/health/ready` (503 при недоступной БД).
Ctrl+C останавливает процессы приложения; база остаётся в Docker с сохранёнными
данными. Остановить базу: `docker compose stop`.

| Команда npm                | Эквивалент make         | Действие                                        |
| -------------------------- | ----------------------- | ----------------------------------------------- |
| `npm run dev`              | `make dev`              | Локальное окружение                             |
| `npm run lint`             | `make lint`             | Политика файлов, формат, ESLint, TypeScript, Go |
| `npm test`                 | `make test`             | Tooling, component и Go unit tests              |
| `npm run check-changed`    | `make check-changed`    | Lint + unit + PostgreSQL + build + UI/auth E2E  |
| `npm run build`            | `make build`            | Production web и два Go-бинарника               |
| `npm run migrate`          | `make migrate`          | Forward-миграции goose к явному DATABASE_URL    |
| `npm run seed`             | `make seed`             | Пока явный отказ; каталог ещё не создан         |
| `npm run test:integration` | `make test-integration` | Реальные PostgreSQL и локальная почта           |
| `npm run test:e2e`         | `make test-e2e`         | Playwright Chromium: темы, меню, a11y, ошибки   |
| `npm run test:auth-e2e`    | —                       | Реальные Go API, PostgreSQL, SMTP и Chromium    |

Windows не требует установки make: команды npm используют тот же обработчик.
Неподключённые наборы завершаются с ошибкой и пояснением; фиктивных зелёных тестов
нет. `make backup`, `make restore-verify`, `make seed-demo` также пока отказывают
в выполнении. Production web после build: `npm run start --workspace @ascend/web`.

Настройки и версии: [dependencies](docs/dependencies.md).
Браузерный набор: сначала `npx playwright install chromium` из `apps/web`,
затем `npm run build:web` и `npm run test:e2e` из корня. Он сам запускает
production web на 127.0.0.1:3100 и останавливает его после тестов.
`check-changed` включает сборку web и E2E; перед ним остановите dev, чтобы
два процесса не меняли один `.next` одновременно.
Локальная БД и сохранность данных: [runbook](docs/runbook.md).

## Текущая готовность

Реализованы C001–C048: серверная платформа, лендинг, адаптивная оболочка,
доступные компоненты, авторизация, профиль, настройки, онбординг и задачи.
`/app` пока показывает статус подготовки, без вымышленных личных метрик.
Работают вход, регистрация, email verification, восстановление пароля и управление
устройствами и смена пароля с проверкой текущего. В аккаунте сохраняются имя,
ник, аватар, IANA timezone, формат дат/времени, рабочие интервалы и дни отдыха,
направления/теги с архивом, приватность, тема, движение и предпочтения интерфейса.
Онбординг можно пропустить, продолжить на другом устройстве и открыть повторно.
Стартовый черновик задачи однократно переносится при открытии раздела задач.
Цель и привычка остаются черновиками до подключения модулей на этапах 07/10.
В `/app/quests` работают создание и редактирование, фильтры и сохранённые
представления, список и Kanban, переходы статусов с причинами, история,
обязательные подзадачи и блокирующие связи, шаблоны, пакетные действия до
50 задач, архив и восстановление. Два редактора получают предупреждение
о конфликте версии. Плановая дата хранится отдельно от дедлайна с часовым поясом.
Вложения приватны: MIME/размер/квоты проверяются сервером, скачивание возможно
после проверки сканером. Локальный антивирус пока не настроен, поэтому новые
файлы остаются на проверке; подключение описано в runbook. XP подключится
централизованно на этапе 11; связь и фильтрация по целям — на этапе 07.
Язык интерфейса — русский; язык дат — ru/en. Социальная публикация не подключена,
профили закрыты. Звук, игровой режим и порядок виджетов сохраняются как предпочтения
для будущих разделов. Личная сводка, цели, календарь и привычки ещё впереди.
Ресурсы и лицензии: [каталог](docs/assets.md).
