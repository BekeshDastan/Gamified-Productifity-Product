# Локальная эксплуатация

## PostgreSQL

`compose.yaml` предназначен только для разработки. База слушает
`127.0.0.1:15432`, чтобы не конфликтовать с обычным PostgreSQL на 5432 и не
открываться в локальную сеть. Требуется явно заданный `POSTGRES_PASSWORD` в `.env`.
Dev-настройки нельзя переносить в production.

Запуск: `docker compose up -d --wait db`. Проверка: `docker compose ps`.
Остановка: `docker compose stop`. Данные сохраняются в volume `ascend-dev_pgdata`.
`docker compose down` также сохраняет volume. Не добавляйте `--volumes`: это
удалит данные. В проекте нет автоматического сброса основной базы.

Для интеграционных тестов будет использоваться отдельная временная схема/БД;
сброс допустим только для созданного этим тестом изолированного окружения.

## Ограничения текущего этапа

Доменные миграции, backup/restore и production deployment ещё не подключены.
Готовность каждого пункта отмечается в ТЗ и журнале разработки.
