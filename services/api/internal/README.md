# Границы сервера

`platform` содержит общие механизмы: конфигурацию, БД, часы, HTTP, очередь,
хранилище и почту. Модули auth, profile, quests и следующие добавляются по плану.

В каждом доменном модуле transport/DTO вызывает application service. Сервис
задаёт транзакцию и зависит от repository interface; PostgreSQL adapter реализует
хранение. Бизнес-правила не переносятся в web или worker. Пустые модули и
универсальные репозитории без конкретной задачи не создаются.
